## ✅ Getting Started
### To run this portfolio locally
```bash
# Clone the repo
git clone https://github.com/SynaptrixAsim/asim-saifi.git
cd asim-saifi

# If frontend uses npm/yarn
cd frontend
npm install
npm start

# If backend exists
cd ../backend
pip install -r requirements.txt
uvicorn main:app --reload
```
